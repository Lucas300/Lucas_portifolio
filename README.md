# 📝 Blog Pessoal - Frontend

Este é o frontend do projeto **Blog Pessoal**, desenvolvido com **React**, **TypeScript**, **Tailwind CSS** e **Vite**.  
A aplicação permite que usuários autenticados realizem o **cadastro, edição e exclusão de postagens e temas**.

---

🔗 **Link do Projeto Online:** [https://lucasportifolio.vercel.app/](https://lucasportifolio.vercel.app/)


---

## 🚀 Tecnologias Utilizadas

- ⚛️ [React](https://reactjs.org/)
- 🟦 [TypeScript](https://www.typescriptlang.org/)
- ⚡ [Vite](https://vitejs.dev/)
- 🎨 [Tailwind CSS](https://tailwindcss.com/)
- 🧭 [React Router DOM](https://reactrouter.com/)
- 🌐 [Axios](https://axios-http.com/)
- 🔔 [React Toastify](https://fkhadra.github.io/react-toastify/)

---

## 💻 Funcionalidades

- ✅ Autenticação de usuários (login e cadastro)
- 📝 Criação, edição e exclusão de postagens
- 🏷️ Criação, edição e exclusão de temas
- 🔐 Controle de acesso por token
- 📱 Layout responsivo com Tailwind

---

## 🛠️ Requisitos para Rodar o Projeto

Antes de começar, certifique-se de que você tenha instalado em sua máquina:

- [Node.js](https://nodejs.org/) (versão recomendada: 16 ou superior)
- Um gerenciador de pacotes:
  - [Yarn](https://yarnpkg.com/) (versão recomendada: 1.x ou 3.x), **ou**
  - [npm](https://www.npmjs.com/) (que já vem junto com o Node.js)

Para verificar se você já tem instalado, execute no terminal:

```bash
node -v
yarn -v    
npm -v   
```
---

## 📦 Instalação Local

1. **Clone o repositório:**

```bash
git clone https://github.com/Lucas300/BlogPessoal_React
```
2. **Instale as dependências:**

```bash
yarn install
```

3. **Rode a aplicação:**

```bash
yarn dev 
```

4. **Se deu tudo certo, você pode acessar sua aplicação em seu localhost:**

```bash
http://localhost:5173/
```
